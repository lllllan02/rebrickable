## 翻译约定

- Trans → 透明
- Chrome → 电镀
- Pearl → 珍珠
- Metallic → 金属
- Speckle → 斑点
- Glitter → 闪粉
- Opal → 乳光
- Glow In Dark → 夜光
- Light/Dark Bluish Gray → 浅灰 / 深灰（其余 Bluish Gray 仍用「灰蓝」）
- Nougat → 肉色
- Tan → 黄褐色
- Modulex / HO / 得宝 / 童话镇 / Clikits 保留系列前缀

此文档为色名中文源；运行中映射见 `src/lib/color-zh-names.ts`。改译名后请同步该文件。
